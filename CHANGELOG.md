# Changelog

## [0.1.0] — 2026-08-25

### Added

- Windows Tauri editor for homebrew 3DS platformers
- Project library under `Documents/3DSStudio` (Save / Save As / examples)
- Level editor, assets, physics, dialogue, build console
- Toolchain detection, Setup tools wizard, in-app Help
- **Build 3dsx**, **Build CIA**, **3dslink**
- NSIS per-user installer (`3DS Studio_0.1.0_x64-setup.exe`)
- Docs: user guide, toolchain, playing, troubleshooting, privacy, security

### Notes

- Unsigned installer (SmartScreen friction)
- devkitPro not bundled
- No telemetry or auto-update
